# Task-6
Task 6: List and Dictionary Comprehensions

Objective

To learn Python list and dictionary comprehensions for efficient data processing.

Tools Used

- Python
- Jupyter Notebook / Google Colab

Programs Included

List Comprehensions

1. Create a list of squares.
2. Filter even numbers.
3. Convert names to uppercase.
4. Filter passing student marks.
5. Extract words longer than four characters.

Dictionary Comprehensions

6. Create a dictionary of squares.
7. Create a student marks dictionary.
8. Filter products by price.

Concepts Covered

- List comprehension
- Dictionary comprehension
- Filtering using conditions
- Data transformation
- Comparison with traditional loops

Conclusion

This task demonstrates how Python comprehensions simplify collection creation, filtering, and data preprocessing.
